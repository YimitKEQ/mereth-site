Download the launcher

It installs the whole mod list in the right order and checks your files against the server before it lets you connect. All you need is Skyrim Special Edition on PC. Everything else comes from here, and you should not assemble the list by hand.

Download for Windows86 MB, .exe

Downloading and accepting in the launcher enters you into an agreement with the Mereth RP Administration Team. Read the Terms and the Privacy Policy first. The launcher has its own licence, which it shows you on first run. Mereth is 18+.

Order matters as much as files. A plugin present but in the wrong slot fails exactly the way a missing one does, and the server checks names, order, light flags and SKSE checksums before it lets you connect. That is the launcher's job, not yours. If it will not connect, read the exact error first.

This page corrects itself. The lists below are read against the launcher's own live manifest in your browser. The launcher is always the final authority on what your install needs, whatever this page says.
