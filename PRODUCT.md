# Mereth Roleplay

## Register
brand

## Product purpose
The public face of a serious-roleplay Skyrim server running on SkyMP. It has two
jobs: convince a careful roleplayer this place is worth an application, and be
the reference a current player actually uses (wiki, rules, support, shop).

## Users
- **The prospective player.** Reads at night, has been burned by servers that
  promised depth and delivered a Discord with no rules. Wants evidence of
  systems, not adjectives.
- **The current player.** Looking up a profession, a rule, a hold's law. Needs
  answers fast and correct.
- **Staff.** Handling tickets and, later, records and enforcement.

## The setting, which the design has to carry
4E 185, ten years after the White-Gold Concordat. Imperial rule is formally
intact and quietly fraying, Thalmor presence is growing, and that tension is
the point of the fiction. Cold, northern, administrative. Power runs through
holds, ledgers, contracts and writs.

## Tone
Sober. Documentary. The site is a record, not a poster. Understatement reads as
confidence here; hype reads as the servers this one is trying not to be.

## Anti-references
- Gold-foil-on-black fantasy. The reflex answer for the category, and the thing
  every dead server's site already does.
- WoW private server maximalism: jade, dragons, glow, exclamation marks.
- Startup SaaS: hero metric, three identical feature cards, gradient headline.
- Anything that reads as generated. This community's own rules forbid AI-written
  content, so the bar is not "good enough", it is "indistinguishable from a
  person who cared".

## Strategic principles
- Show the systems. 25 professions, holdstones, durability, proximity voice, a
  synchronised world clock. Specifics are the argument.
- Documents are the brand. Contracts, ledgers, court records and writs are what
  makes this server different, so the interface should feel like one.
- Never promise what is not built. The roadmap is public and honest about it.
